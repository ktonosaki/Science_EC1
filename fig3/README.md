# Figure 3

This folder contains the raw data and analysis scripts used for Figure 3.

## Files

- `data/fig3_abnormal_ovule.csv`: counts for abnormal ovule phenotypes reported in the figure analysis.
- `scripts/fig3_logistic.R`: logistic model script used for the main Figure 3 analysis.

## Data provenance

The observation counts in `fig3_abnormal_ovule.csv` are derived from the values embedded in the original analysis script.
