# Figure 3

This folder contains the raw data and analysis scripts used for Figure 3. The count table is stored as a CSV and is read by the analysis script so the data are not duplicated in code.

## Files

- `data/fig3_abnormal_ovule.csv`: counts for abnormal ovule phenotypes reported in the figure analysis.
- `data/fig3_overpenetration_reconstructed.csv`: reconstructed per-pistil percentages used to draw the Fig. 3g over-penetration panel.
- `scripts/fig3_logistic.R`: logistic model script for Fig. 3f (Middle of rSY and Proximal to EC).
- `scripts/fig3_g_overpenetration.R`: reconstructed-percentage plotting script for Fig. 3g (In central cell).
- `plots/fig3_abnormal_ovule_summary.pdf`: publication-style summary plot generated by the script.
- `plots/fig3_g_overpenetration_summary.pdf`: publication-style Fig. 3g over-penetration plot.
- `results/fig3_abnormal_ovule_summary.csv`: quartile and median summary statistics used for the panel overlays.
- `results/fig3_abnormal_ovule_pvalues.csv`: model-based and Fisher exact test p-values used for the figure annotation labels.
- `results/fig3_g_overpenetration_summary.csv`: quartile and median summary statistics for the reconstructed Fig. 3g panel.
- `results/fig3_g_overpenetration_pvalues.csv`: p-value table for the reconstructed Fig. 3g panel.

## Data provenance

The observation counts in `fig3_abnormal_ovule.csv` are the source-of-truth values used by the logistic analysis. The over-penetration panel data in `fig3_overpenetration_reconstructed.csv` are reconstructed values used specifically to reproduce Fig. 3g.
