# Extended Data Fig. 9

This folder contains the data and analysis script for the individual NM-line abnormal-ovule analysis corresponding to the Extended Data Fig. 9 description in the bioRxiv article. The count table is stored as a CSV and is read by the analysis script so the data are not duplicated in code.

## Files

- `data/extdata_fig9_abnormal_by_line_counts.csv`: per-pistil raw counts (`normal`, `abnormal`) for `ec1`, `NM_1`, `NM_2`, and `NM_3`.
- `scripts/extdata_fig9_abnormal_by_line.R`: plot generation and significance testing script using binomial logistic regression likelihood-ratio tests.
- `plots/extdata_fig9_abnormal_by_line_summary.pdf`: publication-style summary plot generated by the script.
- `results/extdata_fig9_abnormal_by_line_summary.csv`: quartile and median summary statistics used for the plot overlays.
- `results/extdata_fig9_abnormal_by_line_pvalues.csv`: pairwise logistic LRT results used for figure annotations.

## Notes

The dataset in `extdata_fig9_abnormal_by_line_counts.csv` is the source-of-truth data used by the analysis script. This preserves the figure-specific data and analysis logic in a transparent, reproducible form for repository storage.
