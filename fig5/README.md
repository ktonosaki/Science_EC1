# Figure 5

This folder contains the raw data and analysis script used for the Fig. 5 seed-normalization analysis. The count table is stored as a CSV and is read by the analysis script so the data are not duplicated in code.

## Files

- `data/fig5_normal_seed.csv`: raw counts used to quantify normal seed formation across genotypes.
- `data/fig5_abnormal_ovule_counts.csv`: per-pistil `normal`/`abnormal` counts used for the Fig. 5e-style abnormal-ovule plot.
- `scripts/fig5_normal_seed.R`: plotting and summary script for genotype comparisons and significance annotations.
- `scripts/fig5_e_abnormal_ovule.R`: abnormal-ovule plotting script corresponding to the Fig. 5e-style comparison.
- `plots/fig5_normal_seed_summary.pdf`: publication-style summary plot generated by the script.
- `plots/fig5_e_abnormal_ovule_plot.pdf`: abnormal-ovule summary plot generated by the Fig. 5e script.
- `results/fig5_normal_seed_summary.csv`: quartile and median summary statistics used for the plot overlays.
- `results/fig5_normal_seed_pvalues.csv`: pairwise logistic LRT results used for figure annotations.
- `results/fig5_e_abnormal_ovule_summary.csv`: quartile and median summary statistics for the Fig. 5e plot.
- `results/fig5_e_abnormal_ovule_pvalues.csv`: pairwise logistic LRT (BH-adjusted) results used for Fig. 5e annotations.

## Notes

The dataset in `fig5_normal_seed.csv` is the source-of-truth data for Fig. 5f-style seed-set analysis, and `fig5_abnormal_ovule_counts.csv` is the source-of-truth data used by the Fig. 5e-style abnormal-ovule script. This archive keeps the figure-specific raw values and analysis logic in one place for transparent reproducibility.
