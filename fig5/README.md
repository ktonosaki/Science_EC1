# Figure 5

This folder contains the raw data and analysis script used for Fig. 5 abnormal-ovule analysis. The count table is stored as a CSV and is read by the analysis script so the data are not duplicated in code.

## Files

- `data/fig5_abnormal_ovule_counts.csv`: per-pistil raw counts (`normal`, `abnormal`) across WT, `ec1`, `NM_1`, `NM_2`, `NM_3`, and `M_1`.
- `scripts/fig5_abnormal_ovule.R`: plotting and summary script using binomial logistic regression likelihood-ratio tests.
- `plots/fig5_abnormal_ovule_summary.pdf`: publication-style summary plot generated by the script.
- `results/fig5_abnormal_ovule_summary.csv`: quartile and median summary statistics used for the plot overlays.
- `results/fig5_abnormal_ovule_pvalues.csv`: pairwise logistic LRT results used for figure annotations.

## Notes

The dataset in `fig5_abnormal_ovule_counts.csv` is the source-of-truth data used by the analysis script. This archive keeps the figure-specific raw values and analysis logic in one place for transparent reproducibility.
